Diseño y desarrollo de una plataforma personal para la difusión de proyectos técnicos, trayectoria profesional y artículos de opinión/blog.

### Características destacadas:
- **Estructura tipo AcademicPages**: Barra lateral con información de contacto, bio y redes sociales.
- **Internacionalización (i18n)**: Soporte completo en español e inglés con selector intuitivo.
- **Modo Oscuro / Claro**: Detección del sistema operativo y cambio manual sin parpadeos visuales (FOUC).
- **Comentarios en GitHub Discussions**: Integración de Giscus para interacción con la comunidad.
- **Despliegue automatizado**: Flujo de integración continua con GitHub Actions para publicación en `jviera.github.io`.
